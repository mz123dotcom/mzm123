# 输出模板

复制后替换方括号内容。

```
【视频生成参数】
模型：[Seedance 2.0 Mini / 需单条 30s 时改 Seedance 2.5]
时长：2 段 × 15 秒
比例：9:16 竖屏
类型：写实古风江湖集市短剧带货广告
场景：江南江湖集市，布幡、木摊位、来往行人，午后暖光，电影感浅景深
人物：古装小贩、古装路人，两段妆造服饰保持一致
产品：[材质 / 颜色 / 形态 / 包装]，概念款，无真实商标
声音：小贩吆喝 + 路人对白 + 女声卖点画外音，古风轻弦乐 + 集市环境声
画面文字：[卖点关键词]、[价格]

【口播台词】
小贩：“[吆喝 + 演示引导 + 报价]”
路人：“[质疑]”“[真香]”
画外音：“[产品定位 + 卖点 + 适用人群]”

【分镜表】
| 时间 | 画面动作 | 台词/声音 | 重点 |
|---|---|---|---|
| 第1段 0-4s | 小贩举货吆喝，路人驻足 | 小贩吆喝 + 集市人声 | 钩子引流 |
| 第1段 4-8s | 路人打量，皱眉质疑 | 路人质疑 | 制造反差 |
| 第1段 8-15s | 小贩拆封展示，准备演示 | 小贩引导 | 停在试用前一瞬 |
| 第2段 0-5s | 路人上手体验，神情惊喜 | 路人真香 | 反转建立信任 |
| 第2段 5-11s | 产品细节特写，卖点字幕弹出 | 女声画外音 | 价值证明 |
| 第2段 11-15s | 多件陈列，镜头推近价格 | 小贩报价逼单 | 成交收口 |

【生成提示】
- 两段分别粘贴到视频工具，绑定同一张人物参考图或同一组首帧
- 剪辑时硬切拼接，不加转场
```
