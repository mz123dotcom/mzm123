# 脚本包规格：四维分析、八件套与负向约束

## 一、四维分析模板

每条脚本包开头固定写这四段，总长控制在 400–600 字，不要展开成大篇幅的用户调研。

### 1. 人群
写三类，每类一句「她缺什么」，再补一句共同点。例如：一是没耐心的上班族，缺的是把护肤压缩到五分钟的耐心；二是被时间切碎的人，缺一段能坐着不动的时间；三是预算有限的年轻人，缺一次低成本的试用。共同点是不信广告信手感，所以视频里必须让人看见「上手、器物在动、身体有反应」三件事。

### 2. 年龄段
给主力区间（例如 22–35 岁），再说明向上和向下延展时在意点的差别：年龄大的更在意温和与耗材，年龄小的更在意外观、声音与收纳。不要写「覆盖 18–60 岁」这种无意义的宽区间。

### 3. 生活场景
给四个具体可拍的场景，每个场景要能回答「几分钟空档、手边有什么」。不要写「日常使用」「居家场景」这类不能开机的描述。

### 4. 话术映射
用表格，四列：

| 人群 | 心里的话 | 对应口播 | 触发点 |
|---|---|---|---|

「心里的话」必须是一句她真会说的疑问，不能是营销话术；「触发点」写这句口播靠什么起效（时间成本低、价格差可见、单手可用等）。

## 二、八件套写法

### 1. 标题三选
三条给不同切入角度：一条冲突型、一条场景型、一条价格型。单条不超过 20 字，不用问句堆叠，不写绝对化词。

### 2. 黄金 3 秒
写清镜头怎么起（景别、人物在做什么）＋一句台词。首镜不放大特写，先给冲突或场景；台词必须能在三秒内说完。

### 3. 五分镜对照表
四列：时间节点 / 画面 / 口播（台词原文）/ BGM。时间按 0–3、3–6、6–9、9–12、12–15 切。画面列写景别、主体动作、关键道具；口播列必须是可直接对着念的原文，带说话人标注；BGM 列写乐器与情绪走向，末镜注明收尾方式。

### 4. 强化结尾
一句台词 + 一个动作。台词只说价格与「先试手感」这类不带承诺的话；动作留在画面上（收袋、关抽屉、抬眼笑），不要结尾只留口播。

### 5. 视频标签
≥6 个，混搭三类：品类词、场景词、人群词。不要全用大词，至少两个是长尾。

### 6. 拍摄要点
4–6 条，覆盖光、道具、服装、动作、机位。要写成可执行的句子（「主光在侧前方 45 度，保留鼻梁自然明暗」），不要写「注意光线」。

### 7. AI 视频逐镜提示词
每镜一段，顺序固定：画幅与场景 → 人物与服装 → 动作 → 镜头景别与运镜 → 光线 → 质感 → 排除项。同一包里所有镜头必须共用同一人物描述与同一光源描述，避免拼接时人在漂移。

### 8. 一次性整合提示词
一段连续文字，先说总参数（时长、比例、题材、统一人物与统一光源），再逐镜列动作，最后接负向约束。控制在一段之内，不要分条。

## 三、负向约束表

每条提示词末尾接上对应条目，整合提示词一次性带齐。

| 类别 | 必须排除 |
|---|---|
| 画面文字 | 字幕、贴纸、水印、二维码、价格贴图；可识别的品牌标识与商标文字 |
| 人物质感 | 塑料脸、蜡像感、过度磨皮、五官漂移、多指或断指、关节反折、口型与台词不同步 |
| 画面稳定 | 人物穿模、道具变形、透视错误、闪烁、跳帧、两镜之间色温跳变 |
| 场景一致性 | 妆发服饰改变、陈设与光线不接、出现现代穿帮物件（电线、塑料瓶、现代包装） |
| 合规表述 | 「原价」「秒杀」「亏本」「最低」「第一」「永久」「彻底」；美白祛斑、抗衰祛皱、提拉瘦脸、修复治疗等功效词 |

## 四、出稿自检

1. 价格数字与用户提供一致，未四舍五入、未叠加未确认的赠品
2. 全文无「原价」字样
3. 无功效暗示、无绝对化用语、无玄学词
4. 每条提示词末尾带齐负向约束
5. 同一包内人物、服装、光源描述前后一致
6. 八件套齐全，缺一件即视为未完成

## 五、交付文档参数

- 需要 Word 时：A4、上下左右 2.5 cm；标题黑体 18 pt 居中，一级标题黑体 16 pt，正文宋体 12 pt、1.5 倍行距，分镜表宋体 10.5 pt、表头浅灰底
- 文档首段必须写明：题材、画幅 9:16、两段各 15 秒、SeedMini 2.0、价格口径
- 只在对话里输出时，按「四维分析 → 主套路八件套 → 备选 A → 备选 B」的顺序，用标题分块，不写成散文
