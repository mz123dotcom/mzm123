# 成品案例库

六套已验证的案例。换品时照结构改写：入参 4 项 → 第一段三段 → 第二段三段。

## 1. 固体香膏（香氛）

入参：蝶形浅金雕花香膏，缀珍珠流苏，淡青礼盒｜卖点：淡雅持久、随身补香、不刺鼻、中式礼盒｜价格：3 盒〔价格〕

- 0–4s 小贩举香膏吆喝，路过的姑娘停下｜小贩："走过路过，蝶影香膏，一抹生香！"
- 4–8s 姑娘打量，皱眉｜路人："小小一块，香气能留多久？"
- 8–15s 小贩开盒展示膏体，示意上手试｜小贩："姑娘不妨一试，清雅不浓烈！"
- 0–5s 姑娘指尖轻抹、抬手闻香，眼睛一亮｜路人："香气温润，果然不俗！"
- 5–11s 雕花、流苏特写，字幕：淡雅持久、随身补香｜画外音："中式蝶形香膏，留香绵长，出门补香很方便。"
- 11–15s 多盒陈列，镜头推近价格｜小贩："3 盒〔价格〕，随身带，喜欢直接带走！"

## 2. 酸枣仁百合茶（养生茶饮）

入参：棉纸茶包、粗陶茶盏、牛皮纸简装｜卖点：温润顺口、配料简单、熬夜后喝着舒服｜价格：5 袋〔价格〕

- 0–4s 小贩拎茶罐吆喝，疲惫路人驻足｜小贩："安神茶汤，心烦难眠的客官看过来！"
- 4–8s 路人摇头｜路人："一包草茶，真能舒缓心神？"
- 8–15s 小贩提壶注水，茶汤透出浅黄｜小贩："先看汤色，尝一口便知！"
- 0–5s 路人抿一口，舒展眉头｜路人："入口温润，心头都松快不少！"
- 5–11s 茶包、茶汤特写，字幕：温润顺口、配料简单｜画外音："酸枣仁配百合，熬夜后、心绪不宁时喝着舒服。"
- 11–15s 茶品码放，镜头给价｜小贩："5 袋〔价格〕，睡前一杯，安心入寐！"

注意："安神""入寐"贴近功效，正式对外投放建议改为"睡前一杯，喝着舒坦"。

## 3. 艾草护膝（日用穿戴）

入参：深青灰针织护膝，暗纹艾草刺绣，棉布袋｜卖点：贴合关节、保温久、久站走动不僵｜价格：两对〔价格〕

- 0–4s 小贩举护膝吆喝，赶路的中年路人揉膝盖停下｜小贩："艾草护膝，护着膝盖，走路轻松！"
- 4–8s 路人捏了捏，不太信｜路人："这布套，能暖到膝盖里面？"
- 8–15s 小贩展开护膝露出内胆，示意戴上｜小贩："客官戴上试试，暖意慢慢上来！"
- 0–5s 路人戴好稍候，神情放松｜路人："暖暖的，僵疼感缓了不少！"
- 5–11s 刺绣、内胆特写，字幕：贴合关节、戴着暖｜画外音："内里填充艾草，久站受凉时戴着舒服。"
- 11–15s 多对叠放，镜头推价｜小贩："两对〔价格〕，爸妈、劳作之人都合适！"

## 4. 桂花软糕（食品零食）

入参：米白方形糕块、撒干桂花、油纸包装｜卖点：清甜不腻、桂花香足、软糯不粘牙｜价格：4 盒〔价格〕

- 0–4s 小贩托糕吆喝，大姐停步｜小贩："桂花软糕，香甜软糯，走过别错过！"
- 4–8s 大姐有点顾虑｜路人："看着甜滋滋的，怕是腻口吧？"
- 8–15s 小贩掰开一块递上｜小贩："您尝一小块，清甜不齁！"
- 0–5s 大姐咬一口，面露欢喜｜路人："桂花清香，一点不腻！"
- 5–11s 糕体断面特写，字幕：清甜不腻、软糯不粘牙｜画外音："古法桂花糕，配茶当小点心正合适。"
- 11–15s 盒装堆叠，镜头给价｜小贩："4 盒〔价格〕，当茶点、随身小食都可！"

## 5. 整木檀木梳（日用好物）

入参：深棕檀木梳、梳齿流畅、棉布袋收纳｜卖点：顺滑不扯发、手感温润、送礼体面｜价格：一把〔价格〕

- 0–4s 小贩举木梳吆喝，姑娘拢着打结的头发停下｜小贩："檀木好梳，梳发顺而不扯！"
- 4–8s 姑娘翻看，半信半疑｜路人："寻常木梳，梳着容易扯断头发。"
- 8–15s 小贩提梳轻梳一缕发丝演示｜小贩："客官亲身试一下便知！"
- 0–5s 姑娘自己梳，发丝顺滑，惊喜｜路人："果真顺滑，一点不拉扯！"
- 5–11s 梳齿、木纹特写，字幕：顺滑不扯发、手感温润｜画外音："整块檀木打磨，日常梳头、送人都雅致。"
- 11–15s 几把并排，镜头推价｜小贩："一把〔价格〕，自用送礼两相宜！"

## 6. 草本润眼贴（护眼）

入参：淡绿独立眼贴、素色纸盒｜卖点：清凉舒缓、用眼久了敷着舒服、便携｜价格：10 袋〔价格〕

- 0–4s 小贩摆眼贴吆喝，揉眼睛的书生模样路人停下｜小贩："草本眼贴，眼干酸胀的客官瞧一瞧！"
- 4–8s 路人挑眉｜路人："薄薄一片，真能舒缓酸胀？"
- 8–15s 小贩拆开一片展示薄贴，示意贴上｜小贩："贴上静候片刻，自有清凉感！"
- 0–5s 路人贴上、取下、眨眨眼｜路人："冰冰凉凉，眼睛松快多了！"
- 5–11s 眼贴特写，字幕：清凉舒缓、便携好贴｜画外音："看书、盯屏幕久了，敷一会儿舒服些。"
- 11–15s 多盒陈列，镜头给价｜小贩："10 袋〔价格〕，读书看卷、熬夜都能用！"

## 换品速查

- 有试用动作的品（膏、乳、贴、戴）：反转靠体感
- 无试用动作的品（食品、茶）：反转靠入口与气味反应
- 数码：反转靠一记可见的动作结果（开机、切界面、抬手提起来很轻）
