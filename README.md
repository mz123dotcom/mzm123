# 古风集市短剧带货脚本 · 豆包版

一个给豆包用的技能：把任意商品写成「古风江湖集市 · 小贩吆喝 + 路人质疑反转」的竖屏带货短剧脚本。

**全程免费创作**：不需要买视频模型、不需要配 API Key、不需要开会员。豆包读了这个技能，直接给你出分镜、台词和画面提示词。

## 在豆包里怎么用

把整个 `SKILL.md` 发给豆包，然后说一句话就能开写：

> 用古风集市短剧带货脚本，帮我写【产品名】，卖点是【两三条】，价格【多少】，外观【颜色/材质/包装】

豆包会自动输出：视频生成参数 + 口播台词 + 两段分镜表 + 可直接粘贴的画面提示词。

想让它长期生效，就把这个目录放到 `~/.doubao/agent_mode/workspace/.user_skills/`，之后只要提到“古风卖货短剧”“反差剧情带货”就会自动触发。

## 它长什么样

固定结构：**两段 × 15 秒、9:16 竖屏**

| 段落 | 内容 |
|---|---|
| 第一段 | 小贩举货吆喝 → 路人拆台质疑 → 拆封准备演示（停在试用前一瞬） |
| 第二段 | 路人试用反转 → 产品特写 + 卖点画外音 → 陈列报价逼单 |

举个例子（檀木梳）：

- 0–4s “檀木好梳，梳发顺而不扯！”
- 4–8s 路人：“寻常木梳，梳着容易扯断头发。”
- 8–15s 小贩：“客官亲身试一下便知！”
- 0–5s 路人：“果真顺滑，一点不拉扯！”
- 5–11s 梳齿木纹特写 + 卖点字幕
- 11–15s “一把〔价格〕，自用送礼两相宜！”

## 为什么分两段

主流 AI 视频模型单条普遍限制 15 秒。拆成两段、绑定同一张人物参考图，人物不漂移，剪辑时硬切拼接即可。要单条 30 秒，就改用支持 30 秒的模型，把两段合成一条。

## 免费创作的边界

- 脚本生成完全免费，豆包均能完成
- 真要出片，用豆包自带的视频生成能力，或用 Seedance / 即梦等工具，那段需要各自的额度
- 产品一律描述为概念款，不出现真实品牌、logo、明星肖像，规避版权
- 护肤不说疗效、食品不说功效、价格只来自你提供的信息
