# 古风集市短剧带货脚本 Skill

一个用于 AI Agent 的 Skill：把任意商品改写成「古风江湖集市 · 小贩吆喝 + 路人质疑反转」的竖屏带货短视频脚本，输出可直接投入 Seedance / 即梦等 AI 视频工具的分镜与提示词。

## 它产出什么

固定结构：**两段 × 15 秒、9:16 竖屏**

| 段落 | 内容 |
|---|---|
| 第一段 | 小贩举货吆喝 → 路人拆台质疑 → 拆封准备演示（停在试用前一瞬） |
| 第二段 | 路人试用反转 → 产品特写 + 卖点画外音 → 陈列报价逼单 |

每段交付：视频生成参数、口播台词、分镜表、可单独粘贴的画面提示词。

## 目录结构

```
gufeng-market-skit-video-script/
├── SKILL.md                            # 主流程：入参、世界观、两段骨架、输出格式、合规红线
├── references/
│   ├── story-framework.md              # 节拍公式、钩子/质疑/反转变体、常见失误
│   ├── case-library.md                 # 六套成品案例（香氛/养生茶/日用/食品/木梳/护眼）
│   └── category-compliance.md          # 分品类话术与禁用词清单
└── assets/
    └── script-template.md              # 输出模板与单段画面提示词模板
```

## 怎么用

1. 提供 4 项入参：产品名称、核心卖点（2–4 条）、价格话术、外观描述
2. Agent 读取 `SKILL.md`，按骨架输出两段完整脚本
3. 每段绑定同一张人物参考图生成视频，剪辑时硬切拼接、不加转场

示例入参：

> 产品：整木檀木梳｜卖点：顺滑不扯发、手感温润、送礼体面｜价格：一把 39.9｜外观：深棕檀木梳、梳齿流畅、棉布袋收纳

## 安装

放到 Agent 的 user skills 目录即可：

```bash
cp -r gufeng-market-skit-video-script ~/.doubao/agent_mode/workspace/.user_skills/
```

目录内 `SKILL.md` 的 frontmatter（`name` + `description`）是唯一触发依据，Agent 在识别到「古风卖货短剧 / 反差剧情带货 / 集市吆喝口播」等意图时自动加载。

## 设计要点

- **两段而非一条 30 秒**：主流 AI 视频模型单条限制 15 秒，分段生成才能保人物一致
- **真质疑而非假质疑**：路人必须说出观众心里的顾虑，反转才有说服力
- **合规前置**：护肤不说疗效、食品不说功效、价格只来自用户提供，品类禁用词单独成表
